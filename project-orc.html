Organic Rankine Cycle Study for Thermal Oil Waste Heat Recovery

Note: Full project documentation is available in German.

Project Overview

This study was created together with Tobias Plenk. It evaluates an Organic Rankine Cycle (ORC) for converting thermal-oil waste heat into electricity. My part of the work focused on comparing different working media, while the overall process was modelled as a university project in process simulation with a focus on feasible operating points and thermodynamic consistency.

Methodology

  • HYSYS process model with design adjustments
  • Pinch condition analysis and operating point selection
  • MATLAB-based parameter sweep and evaluation workflow
  • CoolProp property data for working-fluid calculations
  • n-Pentane as the working fluid for the ORC

Technical Focus

The work compares different temperature and pressure settings for the ORC and checks them against heat-exchanger constraints. The workflow is intended to make the parameter study reproducible and to support a clear assessment of the cycle behaviour under varying boundary conditions.

Tools & Skills

  • Process Simulation
  • Thermodynamics and Heat Transfer
  • Aspen HYSYS
  • MATLAB
  • CoolProp
